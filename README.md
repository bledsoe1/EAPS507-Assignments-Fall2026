# Assignments for EAPS 507 – Fall 2026

## Repository Overview

This repository contains my EAPS 507 coursework for Fall 2026. It includes Jupyter notebooks and supporting assignment materials focused on Python programming, scientific data analysis, and multidimensional arrays.

The purpose of this repository is to organize my coursework, document my progress, and use version control to support reproducible scientific work.

## Assignments

### 1. Python Fundamentals Through Examples
**File:** `01_Calculating_e.ipynb`

Practices Python programming and mathematical calculations, including approximating the mathematical constant *e*.

### 2. In-Class Review of Past Lectures
**File:** `02_In_Class_Review.ipynb`

Reviews Python functions, recursion, variable scope, and the use of external libraries such as NumPy and Matplotlib.

### 3. Data Manipulation – Pandas
**File:** `03_Pandas_Data_Manipulation.ipynb`

Explores how to inspect, select, filter, and summarize geographic data using Pandas. It also covers missing values, grouping, and data manipulation techniques.

### 4. Xarray Assignment and Tutorial
**File:** `04_Xarray_10_Minute_Tutorial.ipynb`

Introduces Xarray and its use in working with labeled, multidimensional scientific data.

### 5. Reading Assignment – Multidimensional Arrays Basics
**File:** `Reading Assignment - Multidimensional arrays basics.pdf`

Covers foundational concepts related to multidimensional arrays and their use in scientific computing.
